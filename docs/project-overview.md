# Money Library Project Overview

## Introduction

The Money Library is a TypeScript-based utility for handling financial calculations with precision and reliability. This library aims to provide simple, yet powerful functions for monetary operations while ensuring accuracy in financial computations.

## Core Features

- Basic arithmetic operations for money values (add, subtract)
- Currency support
- Proper decimal handling to avoid floating-point errors
- Type safety through TypeScript

## Project Goals

1. Create a reliable, well-tested money handling library
2. Demonstrate automated workflow management with n8n and AI
3. Showcase test-driven development practices
4. Maintain comprehensive documentation
